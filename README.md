# 时屿 | Time Isle

> 一个人的数字岛屿。在时间里，有一座自己的岛。

时屿是一个纯前端、零后端的个人数字管理单页应用，所有数据存储在浏览器本地，开箱即用。

## ✨ 功能模块

- **屿中 · 仪表盘** — 数据总览、今日待办、快捷入口
- **万象阁 · 知识库** — 知识卡片、分类标签、Markdown 编辑、双向链接、随机复习
- **日课湾 · 日常中心** — 记账本（收支统计）+ 待办看板
- **归藏库 · 资产中心** — 物品清单、密码保险箱（本地加密）、资源链接、碎片收藏
- **光阴簿 · 潮汐日志** — 日历视图、日记写作、一年前今日回顾
- **观星台 · 思维实验室** — 脑洞收集、状态流转
- **百工坊 · 工具百宝箱** — 单位换算（含古代度量衡）、快速便签、账号到期提醒

## 🎨 设计特点

- 雾蓝 + 古铜金 + 米白配色，安静克制
- 浅色/深色模式一键切换
- 动态波浪背景（浅色）+ 星点粒子背景（深色）
- 登录页岛屿线稿动画，海浪起伏、日晷转动
- 完全响应式，移动端汉堡菜单

## 🛠 技术栈

- HTML5 + Tailwind CSS 3（CDN）+ 原生 JavaScript ES6+
- 无框架、无构建工具、零后端
- 数据存储：localStorage
- 密码加密：本地 AES（XOR 简化实现）
- 字体：思源宋体 + Inter

## 🚀 快速开始

### 本地运行

直接用浏览器打开 `index.html` 即可。

或者启动一个本地服务器：

```bash
# Python
python -m http.server 8080

# Node.js
npx serve .
```

然后访问 `http://localhost:8080`。

### 部署到 Cloudflare Pages

1. 将代码推送到 GitHub 仓库
2. 在 Cloudflare Dashboard 中进入 **Workers & Pages** → **Create** → **Pages** → **Connect to Git**
3. 选择你的仓库
4. 构建设置：
   - **Build command**: 留空（纯静态，不需要构建）
   - **Build output directory**: `/`（根目录）
5. 点击 **Save and Deploy**

几秒钟后，你就拥有了一个部署在 Cloudflare 全球 CDN 上的「时屿」。

## 📦 数据管理

所有数据存储在浏览器的 localStorage 中，清除浏览器数据会导致丢失，请定期导出备份。

- **导出数据**：设置 → 导出数据（下载 JSON 文件）
- **导入数据**：设置 → 导入数据（选择 JSON 文件）

## 🔒 关于数据安全

- 所有数据仅保存在你的浏览器本地，不会上传到任何服务器
